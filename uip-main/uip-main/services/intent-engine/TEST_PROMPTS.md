## Testing the buildPrompt Function

### Using the Test Script

```bash
cd services/intent-engine
npx tsx test-build-prompt.ts
```

### Manual Testing Example

```typescript
import { buildPrompt } from './src/intent-library-loader';

// Test 1: Strategic Planning
const prompt1 = buildPrompt(
  'Intent_Library_Ollama_Enterprise_Ready.xlsx',
  'Strategic planning',
  'llama3',
  'Planning 2026 company strategy under budget constraints'
);
console.log('Test 1:', prompt1.substring(0, 200));

// Test 2: Code Generation
const prompt2 = buildPrompt(
  'Intent_Library_Ollama_Enterprise_Ready.xlsx',
  'Code generation',
  'codellama',
  'Generate REST API endpoint for user authentication'
);
console.log('Test 2:', prompt2.substring(0, 200));

// Test 3: Risk Assessment
const prompt3 = buildPrompt(
  'Intent_Library_Ollama_Enterprise_Ready.xlsx',
  'Risk assessment',
  'llama3',
  'Assessing risks of launching new product'
);
console.log('Test 3:', prompt3.substring(0, 200));
```

## Quick Test Commands

```bash
# Test with specific intent
npx tsx -e "import { buildPrompt } from './src/intent-library-loader'; console.log(buildPrompt('Intent_Library_Ollama_Enterprise_Ready.xlsx', 'Strategic planning', 'llama3', 'Planning 2026 strategy'));"

# Run full test suite
npx tsx test-build-prompt.ts
```

## Expected Output Format

Each prompt should return a formatted string like:

```
SYSTEM:
{System Prompt for the model}

DEVELOPER:
{Developer Prompt}

USER:
Intent: {intent} Context: {context} Produce output strictly matching the JSON schema.

OUTPUT FORMAT (STRICT JSON):
{JSON Schema}
```

## Notes

- Make sure your Excel file has all required columns
- Intent names must match exactly (case-insensitive)
- Models supported: `llama3`, `mistral`, `codellama`
- Context can be any string describing the use case
